# OCTAGON Mobile

Мобильное приложение клуба (docs/10-mobile-app.md). Одно приложение для всех
ролей: разделы показываются по правам, выданным на сервере.

## Запуск

```bash
cd apps/mobile
flutter pub get
```

Адрес API задается при сборке. По умолчанию используется `10.0.2.2` — адрес
хост-машины из эмулятора Android (`localhost` там указывает на сам эмулятор):

```bash
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:3000/api/v1
```

Для реального устройства нужен адрес, доступный из его сети:

```bash
flutter run --dart-define=API_BASE_URL=http://192.168.1.10:3000/api/v1
```

## Проверки

```bash
flutter analyze          # статический анализ
flutter test             # unit- и widget-тесты
flutter build web        # проверка компиляции (не требует Android SDK)
```

`flutter build web` используется для проверки компиляции в окружениях без
Android SDK. Для сборки APK нужен Android SDK, для iOS — macOS с Xcode.

## Структура

```
lib/
  main.dart                  сборка зависимостей и запуск
  app.dart                   корневой виджет, выбор экрана по состоянию сессии
  app_theme.dart             тема: оранжевый акцент, светлый фон (docs/12)
  core/
    api_config.dart          адрес API из --dart-define
    api_client.dart          HTTP-клиент и его интерфейс
    api_exception.dart       ошибка контракта с кодом
    token_storage.dart       токены в защищенном хранилище платформы
  features/
    auth/                    вход, восстановление сессии, выход (H1)
```

## Решения

**Токены в защищенном хранилище.** `flutter_secure_storage`, а не
`SharedPreferences`: access и refresh токены дают доступ к данным клуба, а
SharedPreferences хранит их открытым текстом и включает в резервные копии.

**Абстракции для клиента и хранилища.** `ApiClient` и `TokenStorage` — интерфейсы,
потому что тесты не должны требовать ни сети, ни нативного хранилища. Это
позволило проверить сценарии входа, обновления токена и выхода без запущенного
backend.

**Ошибки объясняются по коду контракта.** «Неверный пароль», «аккаунт
заблокирован» и «слишком много попыток» требуют разных действий, поэтому
`describeAuthError` переводит коды в тексты, а не показывает общее «ошибка».

**Недоступный сервер не разлогинивает.** Если профиль не удалось обновить из-за
сети, сохраненная сессия не стирается: временной сбой не должен означать выход из
аккаунта. Стирание происходит только при отклоненном refresh-токене.
