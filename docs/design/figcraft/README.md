# Экраны в FigCraft

Как я создаю макеты без Figma: экран описывается командами, FigCraft выполняет их
без окна и рендерит PNG. Макет становится воспроизводимым: изменил число —
перегенерировал, и он снова совпадает с интерфейсом.

## Что нужно

`figcraft-cli` из релиза [`storytold/figcraft`](https://github.com/storytold/figcraft)
(v0.10.0): в Windows-архиве `figcraft-0.10.0-windows-x64-portable.zip` рядом с
приложением лежит `figcraft-cli.exe`. Установка в систему не требуется.

На этой машине приложение и CLI лежат в `C:\Users\<user>\FigCraft\`.

## Как пересобрать

```bash
node docs/design/figcraft/build-screens.mjs
figcraft-cli run docs/design/figcraft/screens.json --out docs/design/figcraft/screens.figcraft
figcraft-cli export docs/design/figcraft/screens.figcraft -o docs/design/figcraft/export
```

Экспорт пишет по одному PNG на каждый верхнеуровневый фрейм.

## Как устроено

- `lib.mjs` — общие части: сайдбар, шапка с крошками, заголовок страницы, кнопка,
  карточка, бейдж статуса, поле поиска, фильтр. Всё на токенах проекта
  (`#FF6B00`, `#0E0E10`, `#F7F7F9`), поэтому макет и интерфейс не расходятся.
- `build-screens.mjs` — данные трёх экранов: KPI, строки таблиц, статусы.
- `screens.json` — те же 234 команды в читаемом виде.
- `screens.figcraft` — нативный файл, открывается в приложении.

Ссылки на созданные слои идут через `{"$step": n}`: сначала родитель, потом дети.

## Два правила, которые выяснились на практике

1. **Кнопка, бейдж и поле — это `frame`, а не `rectangle`.** Прямоугольник не может
   содержать слой: текст в него не вложить. Первая сборка упала на этом
   (`114 can't contain layers`), потому что кнопка была прямоугольником.
2. **Порядок шагов важен.** `$step` ссылается на уже созданный слой; скрипт
   выполняется целиком или откатывается, поэтому «создать ребёнка раньше
   родителя» невозможно даже случайно.

## Что можно делать дальше

- **Остальные экраны**: карточка спортсмена, диалоги, состояния пусто/загрузка,
  мобильные 390×844 — тем же способом.
- **Сравнение с кодом**: рендер FigCraft и скриншот админки при 1440 px рядом.
- **Правки в приложении**: открыть `screens.figcraft` в FigCraft, поправить
  руками, затем перенести значения в генератор — или наоборот.
