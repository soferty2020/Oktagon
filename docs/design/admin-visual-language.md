# Визуальный язык админки OCTAGON

Зафиксировано после редизайна карточки спортсмена (#60) и аудита Hallmark.
Документ обязателен для всех новых экранов админки: экраны не должны выглядеть
как разные продукты.

Основа — существующая дизайн-система клуба: тёмный сайдбар, оранжевый акцент,
светлый фон. Она не меняется. Ниже — правила, выведенные из утверждённого макета.

## Токены

Все цвета — только через `@theme` в `apps/admin/src/app/globals.css`.

| Токен | Значение | Назначение |
|---|---|---|
| `--color-ink` | `#0e0e10` | основной текст |
| `--color-muted` | `#6b6b72` | подписи; контраст 5.29:1 на белом |
| `--color-accent` | `#ff6b00` | заливка кнопок, крупные числа |
| `--color-accent-text` | `#b24a00` | оранжевый **текст**: 5.42:1 |
| `--color-accent-soft` | `#fff0e5` | плашки, метки |
| `--color-accent-warm` | `#ffe3cc` | аватары, тёплые акценты |
| `--color-warm` | `#fff8f2` | тёплый фон шапок |
| `--color-warm-edge` | `#f5e6d8` | граница тёплой шапки |
| `--color-canvas` | `#f7f7f9` | фон страницы |
| `--color-line` | `#ededf0` | разделители |

**`--color-accent` нельзя использовать как цвет текста.** `#ff6b00` на белом даёт
2.86:1 — это ниже AA. Для оранжевого текста есть `--color-accent-text`.

## Обязательные правила

1. **Контраст.** Обычный текст — не ниже 4.5:1. Подписи не мельче 12px.
2. **Регистр.** Подписи, заголовки таблиц и метки — обычным регистром. Капс с
   трекингом на мелком тексте запрещён: читается как машинный шаблон.
3. **Без средних точек** в мета-строках. Вместо `Активен · с мая 2025` —
   `Активен, с мая 2025`.
4. **Иконки.** Зазор до текста 12–16px, центры по вертикали совпадают. В коде:
   `flex items-center gap-3`.
5. **Один акцент на экран.** Оранжевый — для главного числа, главного действия и
   текущего состояния. Не для всех ссылок сразу.
6. **Просмотр и правка разделены.** Экран показывает данные; правка — отдельный
   маршрут с «Сохранить» и «Отмена».
7. **Без дублирования.** Факт показывается один раз. Если ступень в шапке — в
   теле её нет.
8. **Пустое состояние — с действием**, а не просто «нет данных».

## Паттерны

### Шапка сущности (спортсмен, тренер, группа, филиал)

- Тёплый фон `bg-warm`, граница `border-warm-edge`, радиус 18px, отступ 28px.
- Два мягких круга `bg-[#FFF1E4]` и `bg-[#FFEBD9]` абсолютом, `overflow-hidden`.
- Слева: аватар-инициалы 76px в круге `bg-accent-warm`, имя 28px bold, статус с
  цветной точкой, чипы связей с иконками.
- Справа: ключевой показатель крупным числом (56px) и его атрибут плашкой,
  ниже — действия.
- Если сущность — не человек, аватар заменяется иконкой того же размера.

### Чип связи

`inline-flex items-center gap-3 rounded-full border border-line bg-white py-2 pl-3.5 pr-4 text-xs`

Иконка 16px слева, текст обычным регистром.

### Карточка раздела

`rounded-card border border-line bg-white p-6`

Заголовок 16px semibold, подпись 12px muted. Внутри — строки с разделителями
`border-b border-line`, отступ строки 16px по вертикали.

### Строка «иконка — подпись — значение»

Иконка 18px `text-[#8A8A92]`, зазор 16px; подпись 12px muted, значение 15px
medium ink.

### Таймлайн

Точка 12px (`bg-accent` для текущего, `bg-line` для прошлого), линия 1px между,
зазор 16px до текста. Текущее состояние помечается плашкой `bg-accent-soft`.

### Действия

Список ссылок с иконками 17px, зазор 12px, шаг строк 36px. Разрушительное
действие — отдельным блоком `bg-[#FDF3F3] border-[#F6DADA]`.

### Вкладки

Сегментированный контрол: контейнер `rounded-xl bg-[#F1EFEC] p-1`, активная
вкладка — `bg-white shadow-sm`. Ссылки, а не состояние клиента: работают без JS.

## Чек-лист нового экрана

- [ ] Цвета только из токенов `@theme`
- [ ] Контраст текста ≥ 4.5:1 (проверять для muted и оранжевого)
- [ ] Нет капса и средних точек
- [ ] Иконки с зазором 12–16px и выравниванием по центру
- [ ] Факты не дублируются между шапкой и телом
- [ ] Просмотр и правка разделены
- [ ] Пустые, частичные и полные состояния продуманы
- [ ] Адаптив: 1440, 1024, 390; горизонтальной прокрутки нет
- [ ] Один акцент на экране
