## Как посмотреть

Открыть `index.html` в браузере. Состояния настоящие: наведение мышью и Tab
показывают hover и focus, `disabled` отключает.

## Как переснять PNG

Скриншоты снимаются Chrome через CDP в трёх ширинах (1440, 1024, 390), полная
высота страницы. Скрипт — `.tools/kit-shots.mjs`, требует запущенный Chrome с
`--remote-debugging-port=9232`.

## Правила, которые заложены

- строка таблицы 48 px — стандарт для всех реестров;
- затемнение под панелью — `#0E0E10` с прозрачностью 32%;
- на мобильном форма полноэкранная, закрытие с несохранёнными изменениями просит
  подтверждение;
- акцент только на действии и активном состоянии, без декоративных KPI;
- данные в примерах вымышленные — цифры и фамилии из референса не переносились.
