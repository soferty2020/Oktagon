# DESIGN.md — OCTAGON Control 2.0

Единая дизайн-система админки. Заменяет разрозненные визуальные решения, не вводя
вторую палитру: всё строится на токенах, которые уже есть в
`apps/admin/src/app/globals.css`.

- Эпик: #124
- Задача: #125
- Статус: спецификация, согласуется до переноса экранов (#131–#134)

## 1. Принципы

1. **Рабочий инструмент, а не витрина.** Плотность важнее воздуха: руководитель
   открывает админку ежедневно и работает с десятками строк.
2. **Один паттерн на один тип данных.** Реестр — таблица, иерархия — группы по
   залам, календарь — недельная сетка, карточка — вкладки. Один экран не смешивает
   два подхода.
3. **Акцент означает действие или состояние.** Оранжевый — главная кнопка,
   активный пункт меню, выбранная сортировка. Не украшение.
4. **Данные только из API.** Нет выдуманных KPI, возраста, расписания, «средних по
   клубу». Нет значения — «Не указано», а не ноль.
5. **Форма не живёт на экране постоянно.** Создание и правка — drawer или отдельный
   маршрут.
6. **Состояние в URL.** Поиск, фильтры, сортировка, страница — восстанавливаются
   при возврате из карточки и переживают перезагрузку.
7. **Доступность не обсуждается.** Контраст ≥ 4.5:1 для текста, `focus-visible` на
   всех интерактивных элементах, `aria-sort` у сортируемых заголовков, страница
   работает с клавиатуры.

## 2. Токены

### Поверхности и текст

| Роль | Токен | Значение | Где |
|---|---|---|---|
| Фон страницы | `--color-canvas` | `#f7f7f9` | контентная область |
| Поверхность карточки | белый | `#ffffff` | таблицы, панели, drawer |
| Основной текст | `--color-ink` | `#0e0e10` | заголовки, значения |
| Вторичный текст | `--color-ink-soft` | `#1a1a1e` | ячейки таблиц |
| Подписи | `--color-muted` | `#6b6b72` | 5.29:1 на белом — минимум для 12 px |
| Границы | `--color-line` | `#ededf0` | разделители, контуры полей |
| Сайдбар | `--color-ink` | `#0e0e10` | только навигация |

### Акцент и состояния

| Роль | Токен | Значение | Правило |
|---|---|---|---|
| Действие | `--color-accent` | `#ff6b00` | заливка кнопок и активного пункта меню |
| Акцентный текст | `--color-accent-text` | `#b24a00` | 5.42:1 — только он, не `--color-accent` |
| Мягкий акцент | `--color-accent-soft` | `#fff0e5` | метки, счётчики, фокус-подложки |
| Успех | `--color-success` | `#2e9e5b` | статус «активна», подтверждения |
| Ошибка | `--color-danger` | `#e23b3b` | ошибки, удаление |
| Предупреждение | `--color-warning` | `#ffa726` | «нет суммы», «черновик» |

### Скругления и сетка

- `--radius-card: 12px` — панели и блоки; `--radius-control: 10px` — поля и кнопки.
- Шаг отступов: 4 / 8 / 12 / 16 / 24 / 32. Внутри карточки — 16–20, между
  блоками — 16, отступ контента — 24–32.
- Сайдбар: 248 px (1440+), 206 px (1024), строка навигации — 36–38 px.

## 3. Типографика

| Роль | Размер / вес | Применение |
|---|---|---|
| H1 страницы | 24–30 / 700 | заголовок раздела |
| H2 блока | 15–16 / 600 | зал, секция карточки |
| Тело | 13–14 / 400 | ячейки, подписи полей |
| Значение в таблице | 13 / 500 для главного поля | ФИО, название группы |
| Подпись | 12 / 400, `--color-muted` | пояснения, вторичные строки |
| Число KPI | 22–24 / 700 | только реальные показатели |

Правила: регистр обычный (никаких капс-лейблов), заголовки таблиц 11–12 px
обычным регистром, перенос длинных названий — `truncate` с `title`, не «…» руками.
Числа выравниваются по правому краю только в денежных колонках, остальные — по
левому, чтобы не терять выравнивание с текстом.

## 4. Паттерны

### 4.1 PageHeader

Заголовок + одна строка описания + основное действие справа. KPI — отдельным
рядом, не внутри шапки. Максимум четыре показателя, каждый — из API.

### 4.2 FiltersBar

Одна строка: поиск (растёт), селекты (зал, группа, статус), «Сбросить» при
активных фильтрах. Значение поиска — в URL (`?search=`), запрос уходит в API, а не
фильтрует загруженную страницу. Фильтр «группа» зависит от «зала».

### 4.3 DataTable

- Первая колонка — главное поле (ФИО, название), оно же ссылка в карточку.
- Сортируемые заголовки — кнопка с `aria-sort`, стрелка ↑/↓ у активного столбца;
  сортировка считается на сервере.
- Вторичная строка под главным значением (зал под группой, возраст под датой) —
  12 px, `--color-muted`; только если это помогает выбору.
- Действия справа: «Открыть» + карандаш. Меню «⋯» — только при двух и более
  операциях, иначе это лишний клик.
- Пагинация внизу: «Показано N из M», номера страниц, переход по первой/последней.
- Пустое состояние — внутри таблицы, с действием («сбросить фильтры», «добавить»).

### 4.4 HallGroup (иерархия)

Заголовок зала: иконка, название, адрес или «Адрес не указан», счётчик групп,
кнопка сворачивания. Внутри — таблица групп. Пустой зал показывается: это факт,
а не ошибка.

### 4.5 Drawer

Ширина 420–460 px, затемнение фона, закрытие по ✕, фону и Esc. Заголовок,
прокручиваемое тело, липкий подвал с «Отмена» и основным действием. Ошибка — над
кнопками, с текстом причины, а не «что-то пошло не так».

### 4.6 Tabs (карточка)

Профиль, аттестации, оплаты, посещаемость, история. Каждая вкладка — ссылка с
сохранением контекста; активная подчёркнута акцентом. Дубли между шапкой и
вкладками запрещены: факт показывается один раз.

### 4.7 StatusBadge

Мягкая подложка + текст: «активна» (зелёный), «черновик» (янтарный), «архив»
(серый), «не установлена сумма» (янтарный). Без декоративных точек.

### 4.8 Состояния

| Состояние | Как выглядит |
|---|---|
| Загрузка | скелетон строк таблицы, а не пустой экран |
| Пусто (нет данных) | объяснение + действие |
| Пусто (фильтры) | «по выбранным условиям нет» + «сбросить» |
| Ошибка API | текст причины + «Повторить», фильтры сохраняются |
| Нет прав | 403-страница без намёка на существование данных |

## 5. Адаптив

| Ширина | Поведение |
|---|---|
| 1440 | сайдбар 248, таблица целиком, до 6 колонок |
| 1024 | сайдбар 206, скрываются второстепенные колонки (расписание → подпись под названием) |
| 390 | навигация строкой, таблица превращается в карточки, формы в одну колонку, KPI 2×2 |

Правило: на мобильном у строки остаются название, статус и действие; остальное —
вторичными строками. Горизонтального скролла таблиц нет.

## 6. Правила контента

- «Нет данных» ≠ «0». Пустая сумма — «Не указана», пустая дата — «Не указано».
- Названия — как в клубе («Дети 5–7 лет»), а не как в БД (`GROUP_5_7`).
- Служебные идентификаторы, enum'ы и технические статусы в интерфейс не попадают.
- Персональные и финансовые данные — только при соответствующем праве; UI не
  подсказывает, что поле существует.
- Ошибка объясняет, что делать: «Проверьте название и зал», а не «Ошибка 422».

## 7. Антипаттерны

- Постоянно открытая форма справа, отнимающая треть списка.
- KPI ради красоты: «средний возраст», «процент заполненности», фиктивные числа.
- Капс-лейблы, средние точки в мета-строках, декоративные иконки у каждого пункта.
- Градиенты на кнопках и карточках, тени «на всякий случай».
- Двойная рамка иконки/карточки внутри карточки.
- Сортировка в браузере по загруженной странице при серверной пагинации.

## 8. Карта применения

| Раздел | Паттерн | Что меняется |
|---|---|---|
| Обзор | KPI + таблица | убрать декоративные блоки, оставить реальные показатели |
| Спортсмены | DataTable + Drawer | уже приведено, сверить с 4.3 |
| Группы | HallGroup + DataTable + Drawer | уже приведено, сверить с 4.4 |
| Расписание | недельная сетка по залам | новая сетка вместо списка карточек |
| Карточка спортсмена | Tabs + профиль | убрать дубли, добавить историю |
| Тренеры | DataTable | сейчас карточки — перевести на таблицу |
| Залы | DataTable | карточки → таблица с адресом и числом групп |
| Посещаемость | DataTable + фильтры | единая панель фильтров |
| Аттестации | DataTable | единый вид списка и итогов |
| Соревнования | DataTable | единый список турниров и участников |
| Финансы | DataTable + KPI | должники: «не установлена сумма» отдельным блоком |
| Отчёты | DataTable + графики | оставить, выровнять типографику |
| Новости | карточки-строки | единый список с фильтром статуса |
| Чаты | два столбца | выровнять плотность |
| Пользователи | DataTable | единый вид, приглашения — вкладкой |
| Настройки | разделы-карточки | единая сетка, без дублей |

## 9. Открытые вопросы

1. **Референс PNG.** Утверждённый коллаж Control 2.0 в репозитории отсутствует —
   нужен файл от владельца, чтобы сверить детали перед макетами #126–#130.
2. **Токены фокуса и наведения.** В `globals.css` нет явных `--color-focus` и
   `--color-overlay`; предлагается `--color-accent` для фокуса и `#0e0e10` с
   прозрачностью 32% для затемнения drawer.
3. **Плотность таблиц.** Высота строки 44 px (компактно) или 48 px (как сейчас в
   реестре спортсменов) — нужно решение владельца.
