# 00. Project Overview

## Продукт
OCTAGON Club System — внутренняя цифровая платформа карате-клуба OCTAGON.

## Текущая структура клуба
- 3 филиала; на текущем этапе каждый филиал соответствует одному залу;
- один тренер может работать в нескольких филиалах;
- одна группа может заниматься в разных филиалах;
- одна организация;
- ожидаемый рост до 5+ филиалов.

## Пользователи
- родители;
- взрослые спортсмены;
- тренеры, часть из которых выполняет функции администратора;
- руководитель — суперадминистратор.

## Главная бизнес-цель
Убрать ручной учет, видеть посещаемость и оплаты, дать родителям удобный сервис.

## Принцип учетной записи
Аккаунт пользователя не равен карточке спортсмена. Один аккаунт может быть связан с несколькими спортсменами.
