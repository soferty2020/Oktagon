# 02. Functional Requirements

## Аккаунты
- администратор создает пользователя и приглашает его;
- вход по email + пароль;
- один аккаунт может иметь несколько спортсменов;
- взрослый пользователь может быть связан со своей карточкой спортсмена.

## Спортсмен
Поля MVP:
- ФИО;
- дата рождения;
- фото;
- связанный аккаунт;
- филиал;
- группа;
- основной и дополнительные тренеры;
- текущий пояс;
- дата начала занятий;
- статус.

## Группы
- один спортсмен состоит в одной группе;
- у группы может быть несколько тренеров;
- есть основной тренер;
- возраст — информационный параметр, не жесткое ограничение;
- лимит группы отсутствует.

## Расписание
- регулярное недельное расписание создается на квартал;
- поддерживаются праздники, каникулы, сборы;
- можно изменить одно занятие без изменения шаблона;
- можно заменить время, зал, тренера, отменить занятие.

## Посещаемость
Статусы:
- присутствовал;
- отсутствовал;
- уважительная причина.
Редактирование задним числом разрешено без ограничения.

## Родитель
- видит только своих спортсменов;
- переключает спортсмена;
- видит расписание, посещаемость, новости, чат;
- может заранее сообщить об отсутствии;
- может отправить запрос на заморозку.

## Тренер
- по умолчанию видит только свои группы;
- видит данные спортсмена кроме финансов;
- может видеть контакт родителя;
- отмечает посещаемость;
- может писать родителям и группе;
- дополнительные функции выдаются permissions.

## Суперадмин
- полный доступ;
- управление расписанием и permissions;
- финансовые данные;
- dashboard;
- заморозки и оплаты.
