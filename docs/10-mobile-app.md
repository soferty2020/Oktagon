# 10. Mobile App

Одно Flutter-приложение для всех ролей.

## Состояние

Каркас создан: `apps/mobile`, Flutter 3.47.7, Dart 3.13.5.

Сделано:
- **H1 — вход**: экран входа, токены в защищенном хранилище платформы,
  восстановление сессии при запуске, обновление access-токена по refresh, выход;
- **H2 — переключатель спортсменов**: список связанных спортсменов, основного
  выбирает сервер (`isPrimary`), переключение подгружает данные выбранного;
- **H3 — главная участника**: ближайшая тренировка (первое неотменённое занятие
  впереди), посещаемость за текущий месяц с процентом от отмеченных занятий,
  последнее объявление (закрепленное важнее свежего);
- **H4 — расписание**: занятия по дням на месяц вперёд, отмененные пропускаются;
- **H7 — новости**: список опубликованных объявлений, закрепленные сверху;
- **H9 — профиль**: кто вошел, роль, действующие права, выход.

Навигация — нижняя панель из четырёх вкладок (Главная, Расписание, Новости,
Профиль). Вкладки «Чат» нет: раздел не реализован (H8), а пустая вкладка
выглядела бы сломанной. Экраны держатся в `IndexedStack`, поэтому возврат на
вкладку не перезагружает данные.

Статус оплаты не показывается: финансы закрыты для участника (BR-010,
ADR-0013), вопрос вынесен в `docs/25-open-questions.md`.

Не сделано: H5 (детальный экран посещаемости), H6 (планируемое отсутствие),
H8 (чат), H10 (экраны тренера).

Проверки: `flutter analyze` и `flutter test` (37 тестов) в CI (job `mobile`),
плюс `flutter build web` как проверка компиляции. Сборка APK требует Android
SDK, для iOS нужен macOS — в CI их нет.

## SUPERADMIN
Дополнительные административные экраны доступны по permissions. Сложные финансовые и конфигурационные операции приоритетно выполняются в web admin.

## Главная MEMBER
- переключатель спортсменов;
- ближайшая тренировка;
- статус оплаты текущего месяца;
- посещаемость;
- последнее объявление.

## UX
Основной брендовый акцент — оранжевый, фон преимущественно светлый, черный используется для контраста и навигации.
