# 10. Mobile App

Одно Flutter-приложение для всех ролей.

## Состояние

Каркас создан: `apps/mobile`, Flutter 3.47.7, Dart 3.13.5. Сделано H1 (вход):
экран входа, хранение токенов в защищенном хранилище платформы, восстановление
сессии при запуске, обновление access-токена по refresh и выход. Подробности и
команды запуска — `apps/mobile/README.md`.

Остальные разделы (H2–H10) не начаты: главная, расписание, посещаемость,
отсутствия, новости, чат, профиль, экраны тренера.

Проверки: `flutter analyze` и `flutter test` в CI (job `mobile`), плюс
`flutter build web` как проверка компиляции. Сборка APK требует Android SDK, для
iOS нужен macOS — в CI их нет.

## SUPERADMIN
Дополнительные административные экраны доступны по permissions. Сложные финансовые и конфигурационные операции приоритетно выполняются в web admin.

## Главная MEMBER
- переключатель спортсменов;
- ближайшая тренировка;
- статус оплаты текущего месяца;
- посещаемость;
- последнее объявление.

## UX
Основной брендовый акцент — оранжевый, фон преимущественно светлый, черный используется для контраста и навигации.
