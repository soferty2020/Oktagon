# 12. UI Guidelines

## Brand direction
- основной accent: orange;
- white / light gray surfaces;
- black/dark navigation where уместно;
- логотип OCTAGON использовать без перерисовки при наличии оригинального ассета.

## Принципы
- mobile-first;
- крупные touch targets;
- минимальное число действий для посещаемости;
- финансовые статусы должны быть визуально однозначными;
- административные таблицы должны поддерживать поиск и фильтры;
- не использовать цвет как единственный носитель статуса.

## Accessibility
- достаточный contrast;
- scalable text;
- semantic labels;
- keyboard navigation в web admin.
