### Тренеры: почему важен статус доступа

Экран показывает не только карточку, но и **связан ли профиль с аккаунтом**.
Это рабочий статус, а не деталь оформления: тренер без аккаунта не попадает в чаты
своих групп (состав вычисляется по `TrainerProfile.userId`), не видит расписание и
не может отмечать посещаемость. Проверено на живом стенде: без связи тренер
получает 403 при попытке открыть чат своей группы, после привязки — 201.

Права разделены: карточка тренера правится `branches.manage`, привязка аккаунта —
`users.manage`. Это разные полномочия: администратор справочника заводит профиль,
но не выдает доступ в систему.

## Оформление

Интерфейс приведен к макету клуба: тёмный сайдбар с разделами, светлая шапка с
пользователем, оранжевый акцент на активном пункте и основных кнопках. Токены —
в `apps/admin/src/app/globals.css` (Tailwind v4 `@theme`), они совпадают с
палитрой мобильного приложения (`apps/mobile/lib/design/tokens.dart`): сотрудник
переходит между админкой и приложением, и цвета не должны спорить.

Компоненты оформления:

| Файл | Что задает |
|---|---|
| `components/app-shell.tsx` | каркас: сайдбар, шапка, `PageHeader`, `Notice` |
| `components/nav-link.tsx` | пункт меню с подсветкой активного раздела |
| `components/section-title.tsx` | заголовок раздела в шапке по адресу страницы |
| `components/icons.tsx` | 17 SVG-иконок разделов |
| `components/charts.tsx` | `Sparkline`, `BarChart`, `Donut` на SVG |
| `globals.css` | палитра и стили таблиц (`.table-base`) |

Графики нарисованы вручную в SVG, а не библиотекой: нужны три простые формы, а
chart-пакет добавил бы сотни килобайт и клиентский JS туда, где достаточно
серверного рендера.

**Чего на главной нет и почему:** тренды в KPI-карточках (в макете — мини-графики)
не рисуются, потому что API не отдает историю по дням, а фальшивая линия хуже
отсутствия; уведомлений и заявок нет — разделов нет в API; посещаемость построена
по группам, а не по дням недели, потому что сводка считается по группе за период.

## Dashboard MVP
- выручка;
- задолженность;
- количество активных спортсменов;
- новые/ушедшие;
- посещаемость;
- количество спортсменов по группам;
- сравнение филиалов.
