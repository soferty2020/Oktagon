# ADR-0003: Calendar Month Financial Model

Status: Accepted

## Decision
В MVP финансовый учет строится вокруг календарного месяца, а не классического абонемента.

Сумма произвольна. Суперадмин вручную подтверждает, что период оплачен полностью.

## Consequence
Не реализуем тарифный/подписочный движок до post-MVP.
